# Actividad-1
Análisis Exploratorio de Datos (EDA) sobre las unidades económicas urbanas de Colombia, utilizando microdatos del Censo Económico Nacional Urbano (CENU) 2024 del DANE. El proyecto se desarrolla en R y R Markdown e incluye limpieza de datos, análisis estadístico descriptivo, visualización de variables y distribución sectorial y geográfica
